# amos-library

A library of AMOS programs for testing [amos-ts](https://github.com/bitplane/amos-ts)

If you find something that belongs to you here and want it removed, please
raise an issue on [the tracker](https://github.com/bitplane/amos-library/issues)
or email [gaz@bitplane.net](mailto:gaz@bitplane.net).
